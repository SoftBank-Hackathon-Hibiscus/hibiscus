# 개발용 예제

여기 있는 앱 두 개는 이 모듈이 제대로 동작하는지 보려고 만든 작은 샘플입니다. 팀 앱(방명록)이 아닙니다.

- state-loss: 메모를 SQLite 파일로 컨테이너 안에 저장합니다. 시작할 때 테이블을 지우지 않습니다. 같은 컨테이너를 재시작하면 데이터가 남고, 컨테이너를 새로 만들면 사라집니다.
- binding: 127.0.0.1에만 열리는 health 앱입니다. 내 PC에서 바로 켜면 잘 되는데, 컨테이너에 넣으면 밖에서 접속이 안 됩니다.

`baseline/` 아래 기록(session.jsonl)은 손으로 쓴 것입니다. 대신 앱을 PC에서 직접 띄워서 기록과 실제 응답이 똑같은지 테스트로 확인합니다(`tests/premortem/test_samples_local.py`). 기록에 매번 바뀌는 값이 없어서 noise.json은 비어 있습니다.

`fixtures/` 아래 AI 응답은 합성 예시이고 실제 AI 호출 결과가 아닙니다. 실제 호출을 녹화한 파일은 `recordings/`에만 둡니다.
